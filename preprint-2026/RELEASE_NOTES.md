# Software release v1.0.0 — 2026-11-11

This release freezes the code and publicly redistributable research outputs of
*Climate-driven agent-based scenario modeling of Puccinia menthae epidemics in oregano-growing areas of northern Chile*.

## Included
- S-E-I spatial agent-based model and reproducible benchmark/sensitivity scripts.
- DMC RE1018 downloader and documented quality-control logic.
- Historical NetLogo source-rule Python diagnostic (not native NetLogo).
- Independent Monte Carlo convergence runner, two original figures, and 10,500
  individual Monte Carlo scenario results (7 scenarios x 3 localities x 500 reps).
- LICENSES.md: MIT for code, CC BY 4.0 for original figures and simulation-derived results.

## Explicit exclusions
- No meteorological station observations or derived daily weather records from DMC/INIA.
- No original field photographs, private correspondence, or unpublished collaborators' files.
- No claim of local pathogen identification or field-calibrated risk prediction.

## Reproduction limitation
The complete model rerun requires users to acquire RE1018 daily observations
from DMC under the provider's own usage terms. Precomputed model-derived results
are provided to permit reanalysis without redistributing the meteorological records.

The associated manuscript is version 6.3 with the software DOI incorporated (before arXiv submission). The software version 1.0.0 was published on Zenodo on 2026-11-11: https://doi.org/10.5281/zenodo.24142228. An arXiv identifier has not yet been assigned.
